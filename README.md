# ملعب MAL3AB

مشروع Android تجريبي أولي باللغة العربية.

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (وليس ملف ZIP وحده).
2. افتح تبويب Actions.
3. اختر Build Mal3ab APK ثم Run workflow، أو انتظر البناء بعد الرفع.
4. افتح عملية البناء الناجحة ونزّل Artifact باسم `Mal3ab-debug-apk`.

هذه نسخة تجريبية: لا تتضمن بيانات مباريات مباشرة أو إشعارات حقيقية أو بثاً.
